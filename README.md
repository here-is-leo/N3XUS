## 📡 What is N3XUS?

<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=16&duration=2500&pause=600&color=00FFCC&center=true&vCenter=true&width=600&lines=ESP32-powered+EW+platform;2.4GHz+%2B+Sub-1GHz+coverage;Recon+%7C+Attack+%7C+Deceive+%7C+Defend" />

</div>

**N3XUS** is a state-of-the-art, portable **Electronic Warfare (EW) testing toolkit** built around the powerful **ESP32** microcontroller. It integrates **three NRF24L01+ PA+LNA modules** for 2.4GHz operations and a **CC1101 transceiver** for sub-1GHz frequency bands, creating a comprehensive platform for:

<tr>
<td align="center" width="33%">🔍<br><b>RF Reconnaissance</b><br><sub>Full-spectrum scanning & signal analysis</sub></td>

<td align="center" width="33%">🎭<br><b>Deception Techniques</b><br><sub>Rogue AP, MAC spoofing, manipulation</sub></td>
</tr>
<tr>
<td align="center">🛡️<br><b>Network Security Testing</b><br><sub>WPA/WPA2 handshake & PMKID capture</sub></td>
<td align="center">📊<br><b>Real-time Visualization</b><br><sub>TFT display with live statistics</sub></td>
<td align="center">🌐<br><b>Remote Control</b><br><sub>Web dashboard via WiFi</sub></td>
</tr>
</table>


2. Run the installer
3. Follow the wizard, accept the license
4. Choose install directory

**macOS:**
1. Download the Mac version (.dmg)

3. Drag Arduino.app to Applications

## 🛠️ Troubleshooting Guide

</div>

<details>
<summary><b>🔧 Common Issues & Solutions (click to expand)</b></summary>

| Issue | Solution |
|:---|:---|
| 🖥️ **TFT white screen** | 1. Check `User_Setup.h` → Enable `ST7789_DRIVER`<br>2. Verify CS (GPIO 2), DC (GPIO 16), RST (GPIO 5)<br>3. Check 3.3V supply<br>4. BLK pin → 3.3V |
| 📡 **NRF not found** | 1. Add 10µF capacitor VCC↔GND<br>2. Verify CE/CSN pins<br>3. Check 3.3V with multimeter<br>4. Ensure PA+LNA version |
| 📻 **CC1101 fails** | 1. Check CS pin (GPIO 16)<br>2. Install `ELECHOUSE_CC1101` library<br>3. Verify SPI connections<br>4. Check GDO0 pin |
| 💾 **SD not reading** | 1. Format as FAT32<br>2. Max 32GB<br>3. Check CS (GPIO 14)<br>4. Try another card |
| 🌐 **Web panel not loading** | 1. Connect to N3XUS WiFi<br>2. Open http://192.168.4.1<br>3. Disable firewall temporarily |
| ⬆️ **Upload fails** | 1. Remove all wires from ESP32<br>2. BOOT → EN → release BOOT<br>3. Select correct COM port<br>4. Try different USB cable |
| 🔄 **Constant reboots** | 1. Use 5V 2A supply<br>2. Add 1000µF capacitor<br>3. Check power connections<br>4. Check for shorts |
| 🔘 **Buttons not working** | 1. Use `INPUT_PULLUP`<br>2. Verify GPIO → GND<br>3. Check debounce delay |
| 📟 **OLED not working** | 1. Check I2C address (0x3C / 0x3D)<br>2. Verify SDA/SCL pins<br>3. Check 3.3V |
| 📶 **WiFi not connecting** | 1. Verify `AP_SSID` / `AP_PASS`<br>2. Check ESP32 antenna<br>3. Reset device<br>4. Check interference |

</details>

```cpp
// Power Level Options:
// RF24_PA_MIN   - ~-18dBm (lowest)
// RF24_PA_LOW   - ~-12dBm (low)
// RF24_PA_HIGH  - ~-6dBm  (medium)

radio.setPALevel(RF24_PA_LOW);    // Battery saving
```

## 📡 N3XUS چیست؟

<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=16&duration=2500&pause=600&color=00FFCC&center=true&vCenter=true&width=600&lines=پلتفرم+جنگ+الکترونیک+مبتنی+بر+ESP32;پوشش+۲.۴GHz+و+زیر+۱GHz;شناسایی+%7C+حمله+%7C+فریب+%7C+دفاع" />

</div>

**N3XUS** یک جعبه‌ابزار **جنگ الکترونیک (EW)** قابل حمل و پیشرفته است که بر پایه میکروکنترلر قدرتمند **ESP32** ساخته شده است. این پروژه **سه ماژول NRF24L01+ PA+LNA** را برای عملیات 2.4GHz و یک **فرستنده-گیرنده CC1101** را برای باندهای فرکانسی زیر 1GHz ادغام می‌کند و پلتفرمی جامع برای موارد زیر فراهم می‌آورد:

<table align="center">
<tr>
<td align="center" width="33%">🔍<br><b>شناسایی RF</b><br><sub>اسکن کامل طیف و تحلیل سیگنال</sub></td>
<td align="center" width="33%">⚔️<br><b>شبیه‌سازی حمله</b><br><sub>Deauth، تزریق بسته، اختلال</sub></td>
<td align="center" width="33%">🎭<br><b>تکنیک‌های فریب</b><br><sub>AP جعلی، جعل MAC، دستکاری</sub></td>
</tr>
<tr>
<td align="center">🛡️<br><b>تست امنیت شبکه</b><br><sub>ضبط دست‌دادن WPA/WPA2 و PMKID</sub></td>
<td align="center">📊<br><b>نمایش بلادرنگ</b><br><sub>نمایشگر TFT با آمار زنده</sub></td>
<td align="center">🌐<br><b>کنترل از راه دور</b><br><sub>داشبورد وب از طریق WiFi</sub></td>
</tr>
</table>

| مشکل | راه‌حل |
|:---|:---|
| 🖥️ **صفحه سفید TFT** | ۱. `User_Setup.h` → فعال‌سازی `ST7789_DRIVER`<br>۲. بررسی CS (GPIO 2)، DC (GPIO 16)، RST (GPIO 5)<br>۳. بررسی تغذیه ۳.۳V<br>۴. پین BLK → ۳.۳V |
| 📡 **NRF پیدا نمی‌شود** | ۱. افزودن خازن ۱۰µF بین VCC و GND<br>۲. بررسی پین‌های CE/CSN<br>۳. بررسی ۳.۳V با مولتی‌متر<br>۴. اطمینان از نسخه PA+LNA |
| 📻 **CC1101 کار نمی‌کند** | ۱. بررسی پین CS (GPIO 16)<br>۲. نصب کتابخانه `ELECHOUSE_CC1101`<br>۳. بررسی اتصالات SPI<br>۴. بررسی پین GDO0 |
| 💾 **SD خوانده نمی‌شود** | ۱. فرمت FAT32<br>۲. حداکثر ۳۲GB<br>۳. بررسی CS (GPIO 14)<br>۴. تست کارت دیگر |
| 🌐 **پنل وب باز نمی‌شود** | ۱. اتصال به WiFi N3XUS<br>۲. باز کردن http://192.168.4.1<br>۳. غیرفعال کردن موقت فایروال |
| ⬆️ **آپلود شکست می‌خورد** | ۱. حذف همه سیم‌ها از ESP32<br>۲. BOOT → EN → رها کردن BOOT<br>۳. انتخاب پورت COM صحیح<br>۴. تست کابل USB دیگر |
| 🔄 **ریبوت مداوم** | ۱. استفاده از منبع ۵V 2A<br>۲. افزودن خازن ۱۰۰۰µF<br>۳. بررسی اتصالات برق<br>۴. بررسی اتصال کوتاه |
| 🔘 **دکمه‌ها کار نمی‌کنند** | ۱. استفاده از `INPUT_PULLUP`<br>۲. بررسی اتصال GPIO به GND<br>۳. بررسی تأخیر debounce |

| 📶 **WiFi وصل نمی‌شود** | ۱. بررسی `AP_SSID` / `AP_PASS`<br>۲. بررسی آنتن ESP32<br>۳. ریست دستگاه<br>۴. بررسی تداخل |
