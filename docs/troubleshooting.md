\\# راهنمای عیب‌یابی N3XUS



\\## 🚨 مشکلات رایج و راه‌حل‌ها



\\### ۱. TFT سفید است



| علت | راه‌حل |

|-----|--------|

| درایور اشتباه | `ST7789\\\_DRIVER` را در `User\\\_Setup.h` فعال کنید |

| اتصالات اشتباه | CS=GPIO2, DC=GPIO16, RST=GPIO5 را بررسی کنید |

| تغذیه ضعیف | از منبع ۳.۳V پایدار استفاده کنید |



\\### ۲. NRF پیدا نمی‌شود



| علت | راه‌حل |

|-----|--------|

| خازن فیلتر | یک خازن ۱۰µF بین VCC و GND نصب کنید |

| تغذیه | ولتاژ ۳.۳V را با مولتی‌متر اندازه بگیرید |

| پین‌های CE/CSN | مطابق جدول اتصالات بررسی کنید |



\\### ۳. CC1101 کار نمی‌کند



| علت | راه‌حل |

|-----|--------|

| CS اشتباه | CS را به GPIO 16 وصل کنید |

| کتابخانه | `ELECHOUSE\\\_CC1101` را نصب کنید |

| فرکانس | از `setMHZ(433.92)` استفاده کنید |



\\### ۴. SD Card خوانده نمی‌شود



| علت | راه‌حل |

|-----|--------|

| فرمت اشتباه | کارت را FAT32 فرمت کنید |

| ظرفیت بالا | از کارت ۳۲GB یا کمتر استفاده کنید |

| CS اشتباه | CS را به GPIO 14 وصل کنید |



\\### ۵. پنل وب باز نمی‌شود



| علت | راه‌حل |

|-----|--------|

| اتصال WiFi | به شبکه N3XUS متصل شوید |

| آدرس اشتباه | http://192.168.4.1 را وارد کنید |

| فایروال | فایروال را موقتاً غیرفعال کنید |



\\### ۶. دکمه‌ها کار نمی‌کنند



| علت | راه‌حل |

|-----|--------|

| PULLUP | از `INPUT\\\_PULLUP` استفاده کنید |

| اتصالات | GPIO به GND را بررسی کنید |

| Debounce | تأخیر ۵۰ms در کد اضافه کنید |



\\### ۷. برد ریست می‌شود



| علت | راه‌حل |

|-----|--------|

| تغذیه ضعیف | از آداپتور ۵V ۲A استفاده کنید |

| نویز | خازن ۱۰۰۰µF به ورودی برق اضافه کنید |

| اتصال کوتاه | مدار را از نظر اتصال کوتاه بررسی کنید |



\\### ۸. آپلود نمی‌شود



| علت | راه‌حل |

|-----|--------|

| حالت Download | دکمه BOOT را نگه دارید، EN را بزنید |

| پورت اشتباه | پورت COM صحیح را انتخاب کنید |

| کابل USB | از کابل دیتا استفاده کنید |

\\## 🔧 عیب‌یابی گام‌به‌گام



\\### مرحله ۱: تست تغذیه

```bash

1\\. ولتاژ ۳.۳V را با مولتی‌متر اندازه بگیرید

2\\. باید دقیقاً ۳.۳V باشد

3\\. اگر کمتر است، منبع تغذیه را تعویض کنید

مرحله ۲: تست TFT

cpp

// کد تست TFT

\\#include <TFT\\\_eSPI.h>

TFT\\\_eSPI tft = TFT\\\_eSPI();

void setup() {

\&#x20; tft.init();

\&#x20; tft.setRotation(4);

\&#x20; tft.fillScreen(TFT\\\_RED);

\&#x20; delay(1000);

\&#x20; tft.fillScreen(TFT\\\_GREEN);

}

مرحله ۳: تست NRF

cpp

// کد تست NRF

\\#include <RF24.h>

RF24 radio(25, 26);

void setup() {

\&#x20; Serial.begin(115200);

\&#x20; if(radio.begin()) Serial.println("NRF OK");

}
