\## 🎮 کنترل با دکمه‌ها



\### دکمه‌های سخت‌افزاری



| دکمه | عملکرد |

|------|--------|

| \*\*SW1 (Menu)\*\* | تغییر صفحه (Home → Mode → Stats → Settings) |

| \*\*SW2 (Up)\*\* | اجرای حالت فعلی / حرکت به بالا |

| \*\*SW3 (Down)\*\* | تغییر حالت به بعدی / حرکت به پایین |



\### دکمه‌های پنل وب



| دکمه | عملکرد |

|------|--------|

| \*\*ACTIVATE\*\* | فعال/غیرفعال کردن سیستم |

| \*\*EXECUTE\*\* | اجرای حالت فعلی |

| \*\*ATTACK\*\* | حمله مستقیم به همه کانال‌ها |

| \*\*PREV\*\* | رفتن به حالت قبلی |

| \*\*NEXT\*\* | رفتن به حالت بعدی |
